# Globaler Visual Style

## Kamera

- 16:9
- statische CCTV-Perspektive
- leicht erhöhte Montageposition
- ungefähr 24–28 mm Äquivalent
- moderate Perspektive, kein Fisheye
- keine cineastische Tiefenschärfe
- keine Handheld-Anmutung

Das Bild soll wie eine echte Überwachungskamera wirken, nicht wie ein Filmstill.

## Licht

- leicht unterbelichtet
- tiefe, aber lesbare Schatten
- glaubwürdige praktische Lichtquellen
- innen überwiegend Leuchtstoffröhren
- außen Sicherheits- und Nutzbeleuchtung
- keine dramatischen Filmspots

Die Dunkelheit darf Informationen verbergen, aber das Bild nicht unbrauchbar
machen.

## Farbwelt

- kaltes Blau
- Blaugrün
- Grau
- gedämpfte institutionelle Farben
- geringe Sättigung

Warme Lichtquellen dürfen vorkommen, aber Rot bleibt selten und bedeutungsvoll.

## CCTV-Artefakte

- dezentes digitales Rauschen
- leichte JPEG-Kompression
- einzelne Dead Pixels
- minimale chromatische Aberration
- leichte Sensor- oder Exposure-Unregelmäßigkeiten

Die Artefakte sollen vorhanden sein, aber nie das Motiv dominieren.

## Negative Leitplanken

- keine Monster im Vollbild
- keine offene Gewalt
- keine Fantasy-Architektur
- kein extremes Weitwinkel
- keine eingeblendete UI
- keine übertriebenen Horror-Spezialeffekte

## Wiederkehrende visuelle Marker

- gealterter Putz
- graugrüne Wände
- abgenutztes Linoleum
- Beton- und Nutzböden
- Kabelkanäle und Rohre
- institutionelle Türen und Beschläge
- funktionale Möbel
- Spuren mehrerer Renovierungsphasen

Diese Marker müssen so konsistent bleiben, dass jedes Bild klar als Teil
desselben Gebäudes lesbar ist.
